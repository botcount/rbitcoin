Added

- **`--network testnet5`.** BIP 95's Testnet 5: the genesis block mined at mainnet height 975,744, a minimum difficulty of about 1,000,000 (`0x1a0fffff`), no 20-minute minimum-difficulty exception, message start `FIVE`, P2P port 18353, RPC port 18352, `getblockchaininfo.chain` `testnet5`, and `tb` addresses. The conf file takes a bare `testnet5` line or `testnet5=1`, and NixOS `services.rbitcoin.network` takes `"testnet5"`. There are no seeds yet, so name a peer with `--connect`. Every script runs (milestone 0) and there is no minimum chain work.
- **BIP 54 is enforced on testnet5 from block 1.** A period's first header more than two hours before its parent is `time-timewarp-attack`, and a period's last header before the period's first is `time-negative-interval`. A block is invalid with a 64-byte transaction (`bad-txns-size`), a coinbase not timelocked to the height before it (`bad-cb-locktime`, `bad-cb-sequence`), or a transaction whose inputs carry more than 2,500 signature operations (`bad-txns-legacy-sigops`). The official BIP 54 test vectors run in the consensus suite. Mainnet, testnet3, testnet4, signet, and regtest are unchanged.
- **Miners on testnet5 get the coinbase BIP 54 needs.** An SV2 `NewTemplate` carries `coinbase_tx_locktime` (the height before the block's) and `coinbase_tx_input_sequence` `0xfffffffe`. `getblocktemplate` lists `!consensuscleanup` in `rules` and refuses a client that did not name `consensuscleanup`. The mempool refuses a 64-byte transaction (`txn-size-64`) and one over the sigop limit, so neither reaches a template.
